Put yourself on the map

Geospatial visualization with R · beginner exercise (5 minutes)

R runs right here in your browser. You do not need to install anything. Press Run Code and a world map appears.

Your mission

  1. Press Run Code. You see the world, Zealandia in turquoise, and three places.
  2. Change “Chennai” and its two numbers to your hometown (cheat list below). Run again: your place appears on the map.
  3. Change "red" to another colour, for example "orange", "gold" or "hotpink".
  4. Add a fourth place: add a comma and one new value inside each c( ... ).

Replace "Chennai", 80.27 and 13.08 with a place from the cheat list. Keep the quotation marks around the name.

To add a place, put a comma after the last value in each list. For example name = c("Cologne", "Wellington", "Chennai", "Paris"), then add the matching longitude and latitude.

cities <- data.frame(
  name = c("Cologne", "Wellington", "Mumbai", "Paris"),
  lon  = c(6.96, 174.78, 72.88, 2.35),
  lat  = c(50.94, -41.29, 19.08, 48.86)
)
draw_world()
add_places(cities, col = "orange")

Longitude is counted from 0 to 360 so that Zealandia, which crosses the date line, stays in one piece. For other places, search “[city] coordinates”. If the longitude is negative (west), add 360.

What you just did

You turned numbers (longitude and latitude) into a map. draw_world() and add_places() are ready-made helpers; inside they use the same few R ideas from the overview page (lists, tables, plot, polygon, text). This is geospatial visualization: the same idea businesses use to plot stores, customers and deliveries.
